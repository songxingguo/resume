## 总原则

- **双轨节奏**：上午投递/面试，下午作品开发，晚上算法 + 题库；面试密度高时作品让位。
- **当天复盘**：每场面试的新题当天记入面试题库——这是最快的提升循环。
- **周度 KPI**：投递数 / 面试场次 / 入库新题数 / 作品里程碑，每周日晚盘点。

## 投递渠道与目标池

- **渠道**：Boss 直聘（主力）、猎聘、拉勾、脉脉、电鸭社区（远程岗）、前同事内推（淘米 / 阅竞 / 德邦，离职前把关系处好）。
- **目标池**：五年职业规划 §一 的雇主池（腾讯西南、长安软件、赛力斯、中移物联、马上消费、猪八戒、中国汽研、银行科技子公司等）。
- **优先级排序**：有 AI 业务或自研工具 > 鸿蒙 / 车机场景（鸿蒙经验精准匹配）> 多端小程序 > 一般前端岗。
- **节奏**：在职窗口（~11.04）每天 5~10 个；离职后每天 3~5 个新增 + 旧沟通跟进。

## 第 1 周（10.25 日 ~ 11.01 日）在职窗口 · 工位就是自习室

> 现状：上班但没活——**工位空闲时间全部转化为备战时间**，晚上留给回渝事务（清单见下节）。
> ⚠️ 边界提醒：在职期间尽量不写个人项目代码——劳动合同的"职务作品"条款可能让在职期间产出的代码归公司所有；作品只写设计文档，代码 11.04 之后再写。
> 🔒 设备安全守则：公司电脑大概率有终端管控（文件外发审计、屏幕水印、浏览记录），且离职敏感期是日志回查高发期。**公司电脑只用于交接、离职手续和纯浏览**（牛客/课程/文档——不登录个人账号、不下载、不外发）；投递与沟通走个人手机（流量、不连公司 Wi-Fi）；如带个人电脑勿连公司网络（用手机热点），更低调的选择是平板 + 蓝牙键盘 + 纸笔；个人文件只存个人网盘。

- [ ] 10.25（日·今天）：简历 PDF 定稿导出（⌘P，命名"宋兴国-前端开发工程师-6年.pdf"）+ 在线简历同步；P0 四项清零（离职叙事 / 空窗写法 / 数字口径 / 删 React·Java）；建回渝事务清单
- [ ] 10.26 ~ 10.30（周一~周五 · 工位时间块 · 低调组合）：
  - 手机（流量）：投递 5~10 个/天 + 内推打招呼（淘米、阅竞前同事；德邦内部 11.04 前保持低调）
  - 公司电脑：纯浏览——牛客/在线课程/技术文档，不登录个人账号、不下载、不外发
  - 平板/纸笔：看题库、练手写题（debounce、深拷贝、Promise——面试手写本来就是纸面）
  - 晚上回家：大块专注——题库脱稿演练 + 算法 2 题 + 回渝事务电话（退租、租房、物流比价）
  - 原则：白天不求拉满，重活放晚上；7 个工作日，体面和干净优先于效率
- [ ] 10.31（六）：第一次全真模拟面试（AI 扮演面试官或找朋友），录音回听，查漏记入题库
- [ ] 11.01（日）：电话收口回渝大项（上海房子方案定稿——**退房日按 11.06 谈**、永川落脚确认、搬家物流下单）；写离职交接文档；嘉兴告别行已挪到离职后的 11.05（可留宿，更从容）
- [ ] 全周并行：背调联系人打招呼、社保公积金截止月确认、竞业条款核对；面试邀约尽量约 11.07 之后的远程初面

## 第 5 周（11.23 ~ 11.29）作品上线 · offer 评估

- [ ] 作品 #3 上线；**用它模拟面自己一轮**，答不好的题回炉题库
- [ ] 首批 offer 进评估（面试准备清单 §六：薪资 / 业务前景 / 技术成长 / 加班 / 通勤）
- [ ] **决策点**：offer 达底线 → 准备入职收尾；未达 → 进入第 6 周扩大战线

## 第 6 周（11.30 ~ 12.14）收尾或扩大战线

- **分支 A（有达标 offer）**：入职准备；把面试复盘沉淀成 2~3 篇博客（多端兼容、Agent 实践）反哺影响力
- **分支 B（未达）**：
  - [ ] 作品 #1'（多端兼容检查 Agent）冲刺上线
  - [ ] 投递扩大到成都（AI 岗密度）与远程岗（电鸭）
  - [ ] 12 月中：简历升级 AI 全栈版（技能行重排 + 两个作品入项目经验），加投 AI 应用 / Agent 岗
  - [ ] 兜底：runway 逼近 3 个月红线时，按转型准备计划 §三的兜底原则执行——先接匹配的前端 offer
