## 筑基期（第 1-4 周）

### 第 1 周：环境搭建 + TypeScript 基础补强

- [ ] 装好 Node 18+、VS Code、Docker Desktop
- [ ] 复习 TS 核心：泛型、装饰器、异步编程、模块系统
- [ ] 用 Next.js 14 App Router 搭一个空壳项目并部署到 Vercel

**产出**：一个可访问的 Next.js 首页，含路由和简单 API 接口

### 第 2 周：LLM API 调用与 Prompt 工程

- [ ] 注册 DeepSeek / 通义千问 / 硅基流动（国内可用，免费额度够用）
- [ ] 实现：流式输出、多轮对话、System Prompt 注入、JSON mode
- [ ] 学会温度/TopP/MaxTokens 参数调节
- [ ] 做一个"翻译助手"单页：输入中文，流式返回英文

**产出**：可运行的翻译助手页面（前端 + 后端 API）

### 第 3 周：RAG 入门 — 向量数据库 + 文档检索

- [ ] 了解 Embedding 概念，调用 text-embedding-v3 或 bge-m3
- [ ] 安装 Milvus Lite（本地运行最简单）或 Qdrant Cloud
- [ ] 实现：上传 PDF → 切片 → 向量化 → 存入 → 语义检索
- [ ] 结合 LLM 做"基于文档的问答"

**产出**：一个简单的"上传文档 → 提问 → 回答"页面

### 第 4 周：工具调用 Function Calling

- [ ] 学习 OpenAI/DeepSeek 的 Function Calling 格式
- [ ] 自己写 3 个工具函数：天气查询、计算器、网页抓取摘要
- [ ] 让模型根据用户意图自动选择工具、传参、处理结果
- [ ] 理解 Tool Call → Tool Result → Final Answer 闭环

**产出**：一个能"查天气 + 算数 + 搜网页"的对话页面

---

## 核心期（第 5-12 周）

### 第 5-6 周：LangGraph 入门 — 状态机思维

- [ ] 读 LangGraph 官方教程（Python 版即可，JS 版同步出）
- [ ] 理解：State、Node、Edge、Conditional Edge
- [ ] 实现一个"客服分流 Agent"：识别意图 → 分配部门 → 转人工兜底
- [ ] 加入循环：如果回答不满意，允许追问一次

**产出**：一个带状态流转的多步客服 Agent（可本地运行）

### 第 7-8 周：MCP 协议与工具生态

- [ ] 了解 MCP（Model Context Protocol）设计思想
- [ ] 实现一个 MCP Server：暴露文件读写、数据库查询等工具
- [ ] 将 MCP 接入 LangGraph Agent，让 Agent 通过 MCP 操作外部系统
- [ ] 重点：错误处理、超时重试、工具调用日志

**产出**：Agent 通过 MCP 读取 SQLite 数据库并回答业务问题

### 第 9-10 周：RAG 进阶 — 生产级优化

- [ ] 引入重排序（Cohere rerank / BGE-reranker）
- [ ] 实现引用溯源：每个回答附带原文片段和页码
- [ ] 加入 Guardrails：内容过滤、敏感词拦截、幻觉检测（简单规则即可）
- [ ] 性能优化：缓存、批量 Embedding、异步写入

**产出**：一个带引用溯源和内容安全的 RAG 问答系统

### 第 11-12 周：可观测性与评测

- [ ] 集成 Langfuse / Helicone / 自建日志：记录每次请求的 Token 消耗、延迟、工具调用链
- [ ] 建立 Eval 数据集：50 条测试用例，含正确回答、拒绝回答、边缘情况
- [ ] 自动化跑 Eval，输出准确率、召回率、平均 Token 数报表
- [ ] 理解：Precision/Recall/F1 在 Agent 评测中的意义

**产出**：一份完整的 Agent 评测报告（含截图和数据）

## 实战期（第 13-20 周）

### 项目一：个人求职 Agent（第 13-16 周）

**选题理由**：面试时可直接演示，展示对"找工作场景"的理解

- [ ] 上传简历 PDF → 自动解析技能/经历
- [ ] 根据岗位 JD 匹配度分析（RAG 比对）
- [ ] 生成定制化自我介绍/面试问题
- [ ] 可追问：哪些技能需要补强？

**技术栈**：

- Next.js + Tailwind CSS 前端
- LangGraph 工作流（解析 → 匹配 → 生成 → 追问）
- PDF 解析（pdf-parse / langchain document loaders）
- 向量检索（Milvus）+ 重排序

**产出**：可公开访问的求职 Agent 网站 + GitHub 仓库 + README 说明

### 项目二：重庆本地场景 Agent（第 17-20 周）

**选题方向（三选一）**：

1. **汽车售后知识助手**：模拟长安/赛力斯的车主手册 RAG，回答保养/故障问题
2. **政务办事指南 Agent**：爬取重庆政务服务网数据，回答"如何办社保/居住证"
3. **工业设备维保 Agent**：模拟工厂巡检记录，根据故障现象推荐维修步骤

**技术栈**：

- 同上 + 私有化部署尝试（Ollama + qwen2.5:7b 本地跑）
- 增加多轮对话记忆（Redis / SQLite 存储历史）
- 加入"人工转接"兜底按钮

**产出**：第二个完整项目 + 对比评测（在线 API vs 本地模型的成本/效果差异）

## 每日/每周执行模板

**工作日（每天 1.5-2 小时）**：

- 30min：看一篇技术文章/源码（LangGraph examples / MCP spec）
- 60min：动手编码（跟着清单走）
- 15min：记录笔记 + 第二天计划

**周末（每天 4-6 小时）**：

- 集中攻坚本周难点
- 写周报（给自己看）：本周完成了什么、卡在哪里、下周计划

## 避坑提醒

1. **不要追求完美再发**：项目做到 70 分就上线，面试官看的是思路不是 UI
2. **别只学不动手**：每段代码都要自己敲，复制粘贴等于没学
3. **面试前一定要跑通 Demo**：现场翻车是大忌
4. **重庆企业看重落地**：多说"我用这个方案帮 XX 场景省了多少钱/多少人"，少说模型原理
